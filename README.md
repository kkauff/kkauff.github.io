# kkauff.github.io

Personal website built with Next.js, TypeScript, and Tailwind CSS. Automatically deployed to GitHub Pages.

## Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

Visit [https://kkauff.github.io](https://kkauff.github.io) to see the live site.

## Tech Stack

- **Next.js 14** - React framework with App Router
- **TypeScript** - Type-safe JavaScript
- **Tailwind CSS** - Utility-first CSS framework
- **Motion** - Animation library for the entrance and hover interactions
- **MUI** - Icon and avatar components
- **GitHub Actions** - Automated deployment

## Deployment

The site automatically deploys to GitHub Pages when changes are pushed to the `master` branch.

## Analytics & Privacy

This site uses [Google Analytics 4](https://support.google.com/analytics/answer/10089681)
to measure aggregate visitor traffic (page views, approximate location, device
and referrer). It is loaded via [`@next/third-parties`](https://nextjs.org/docs/app/guides/third-party-libraries#google-analytics).

GA4 does not log or store IP addresses, and no personally identifying
information is collected. Data handling is governed by Google's
[privacy policy](https://policies.google.com/privacy). Visitors can opt out with
any standard tracking blocker or the
[Google Analytics opt-out add-on](https://tools.google.com/dlpage/gaoptout).
